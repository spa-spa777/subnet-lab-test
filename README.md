# Subnet Lab v1.2.0 開発版

## 追加機能
- 10問ランダム演習：ネットワークアドレス、ブロードキャスト、使用可能ホスト数、サブネットマスク
- 入力形式チェック、正誤判定、計算解説
- 累計正答率と分野別正答率（localStorage、端末内のみ）
- iPhone PWA・オフライン対応（quiz.jsをキャッシュ）

## 継続機能
- v1.1のIPv4計算、32ビット表示、CIDRスライダー、/24サブネット分割

## テスト環境への反映
1. `subnet-lab` の `develop` ブランチにZIP展開後の全7+1ファイルをアップロード（既存ファイルを上書き）。
2. `subnet-lab-test` の `main` に同じファイルをアップロードしてGitHub Pagesでテスト。
3. 本番用 `subnet-lab/main` はテスト完了まで変更しない。
4. テスト完了後にPull Requestを作成し、mainへマージ。

## 注意
- `/31`、`/32` は今回の演習では出題しません（通常のホスト数計算を練習するため）。
- 学習履歴はSafariのサイトデータ消去や端末変更で失われる場合があります。
- オフライン初回利用にはオンライン状態でページを開き、Service Workerをインストールする必要があります。
