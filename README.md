# Subnet Lab v1.1.0 開発版

v1.0.0の計算機能・CIDRスライダー・ビット表示を保持し、/24を/25〜/30へ分割する視覚化を追加しました。

## GitHubへの反映
1. GitHubの **develop** ブランチを選択。
2. Add file → Upload files でこのフォルダ内のファイルをアップロード。
3. 同名ファイルの更新内容を確認し、**develop** にコミット。mainにはコミットしない。
4. ローカルのindex.htmlを開いて分割結果を確認。
5. GitHub Pagesの本番公開元はmainのまま維持。developへのコミットだけでは開発版をiPhoneの公開URLで試せません。

## 動作テスト
- 192.168.1.18, /26分割 → 192.168.1.0/26, .64/26, .128/26, .192/26の4つ。
- /25 → 2つ、/27 → 8つ、/30 → 64つ。
- 10.10.5.130, /26分割 → 10.10.5.0/24を4分割。
- 既存のCIDR計算・ビット表示に回帰がないこと。

## 開発版のiPhone検証
mainを変更しない場合、開発版は別の検証用URLに配置する必要があります。GitHub Pagesの公開元をdevelopへ変更しないでください。独立した検証用リポジトリ、またはローカルネットワーク上の開発サーバー等で確認します。

## セキュリティ
外部ライブラリ・API呼び出しなし。入力IPはブラウザ内で計算。公開前にファイル内容を確認してください。
